      Representation test suite

      Every address in the collection must parse, re-serialize to the identical string, survive strict percent-encoding, and give the same result PostgreSQL gave for its SQL fiber. Gaps must block execution. The protocol checks test the invariants the spec promises. The coverage table declares what the v0.1 grammar can and cannot represent.

      Filter generator

      Generates random addresses from the grammar (seeded, so a run can be repeated) and passes each one through the filter rules. In the published test run, 2,500 generated addresses were also executed in PostgreSQL; all 1,918 SQL and math results matched the tree evaluator.
